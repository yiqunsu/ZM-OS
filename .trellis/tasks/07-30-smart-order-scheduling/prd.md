# 智能录单与规则排产

## Goal

让 FilmOS 的 OpenClaw 主运行时通过对话完成可人工协同的订单录入和可解释的规则排产：文字或图片中的订单信息实时进入右侧表单，用户明确确认后才下发；排产优先保证订单与机器匹配，并依次减少换料、换产品大类、换厚度、换花纹和换宽度损耗，最后做负载均衡。

## Confirmed facts

- OpenClaw 是主运行时，但当前只支持文本流式回复；LangGraph 回退路径已有表单事件和写操作确认原型。
- FastAPI 是唯一业务入口，OpenClaw 不得直连 PostgreSQL。
- 用户确认排产优先级：材料/配方 > 产品大类 > 厚度 > 花纹 > 宽度 > 负载均衡 > 接单顺序。
- 合并生产第一版采用保守规则：材料/配方、产品大类、厚度和花纹一致，合并宽度不超过机器最大宽度。
- 当前数据没有交期或急单目标，本次不引入交期优化。

## Requirements

1. OpenClaw 主运行时识别录单意图后打开右侧订单表单，并从文字中提取客户、产品、规格、数量、单位、配方和备注等已知字段。
2. 聊天支持选择或直接从剪贴板粘贴 JPG/PNG 图片；图片通过后端受控的多模态提取调用转换成结构化订单字段，不把原始图片写入业务数据库或日志。
3. 已选择或粘贴的图片在输入框内以真实缩略图附件卡片预览，并提供清晰的移除操作；不能只显示文件名。
4. 图片发送时，附件立即从输入框移交给乐观用户消息；服务端接收并持久化后返回独立确认，不等待 Agent 完成识别或回复。只有服务端尚未接收消息时失败，才把文字和图片恢复到输入框。
5. 已发送图片作为聊天附件持久保存，刷新或重新进入所属会话后仍显示真实缩略图；缩略图可点击打开大图并支持缩放、重置和关闭。附件访问必须复用会话归属鉴权，不能暴露本地文件路径、原始文件名或公开静态地址。
6. Agent 提取字段与用户手工编辑可共同作用于同一表单；Agent 不覆盖用户已经编辑的字段；刷新或重新进入会话时恢复尚未关闭或下发的表单及草稿。
7. 右侧“下发订单”按钮可以直接作为用户明确确认；用户在聊天中要求下发时，必须先显示确认按钮，确认后才提交当前表单。
8. 下发成功后关闭右侧表单并允许继续聊天。
9. 用户请求排产时，后端生成确定性、可解释的排产草案，不能由 LLM 自由编造方案。
10. 机器匹配硬约束包括：机器启用、产品大类匹配、宽度可行；订单声明花纹时还必须匹配机器花纹能力。
11. 方案按已确认的换产优先级选择机器和合并订单；只有换产代价相同时才优先负载更低的机器。
12. 排产草案在右侧展示机器、订单、合并宽度、理由和未排订单原因。
13. 用户在聊天中确认排产时显示确认按钮；确认后由单个后端事务重新校验并原子创建全部任务。
14. Agent 和普通页面复用订单与生产 Service；所有写入执行权限、校验、幂等与业务审计边界仍在 FastAPI。
15. 保留 LangGraph 回滚路径，不移除现有 OpenClaw 隔离、会话归属和文本历史能力。

## Acceptance Criteria

- [ ] OpenClaw 模式下输入一段完整订单文字会打开右侧表单并填入可识别字段。
- [x] 上传一张有效 JPG/PNG 可触发结构化提取；无视觉模型配置、无效格式和超限图片给出安全错误。
- [x] 输入框可直接粘贴剪贴板 JPG/PNG；图片与普通文字可以在同一条消息中发送。
- [x] 图片在发送前以真实缩略图卡片预览，右上角可移除，替换或删除后不残留失效预览。
- [x] 点击发送后，图片立即从输入框消失并显示在新用户消息中，不等待 Agent 回复。
- [x] 服务端尚未接收消息时发生网络或校验失败，文字和图片恢复到输入框；服务端已接收但 Agent 识别失败时，消息和附件保留且不回填输入框。
- [x] 图片发送后在用户消息中继续显示缩略图，不能显示随机文件名；完整刷新或重新进入会话后仍显示同一附件。
- [x] 点击已发送缩略图可打开大图，支持 50%–300% 缩放、重置、关闭按钮、Escape 和遮罩关闭；关闭后焦点回到触发缩略图。
- [x] 其他用户不能读取不属于自己会话的附件；附件响应不公开缓存、不暴露服务端路径。
- [ ] Agent 已打开的订单表单及其识别字段、人工编辑字段在刷新或重新进入会话后恢复；关闭或下发后不再恢复。
- [ ] 用户手工修改字段后，后续 Agent 更新不会覆盖该字段。
- [ ] 聊天中说“下发订单”只产生确认卡片；点击确认后创建一次订单、关闭表单并显示订单号。
- [ ] 右侧按钮仍可创建订单，失败时保留表单和错误状态。
- [ ] “帮我排产”返回由后端规则引擎生成的右侧方案，而不是 LLM 自由生成的 JSON。
- [ ] 不匹配机器、缺少宽度、花纹不匹配的订单进入未排列表并包含中文原因。
- [ ] 确认排产时整套方案一次提交；任意任务校验失败时不留下部分生产任务。
- [ ] 并发或过期方案在确认时被拒绝，不会重复占用订单。
- [x] 相关后端测试、Ruff、前端 lint/build 通过。

## Out of Scope

- 交期、急单、班次、维护窗口、机器速度和全局最优求解器。
- PDF、多页文档、多附件消息、批量图片生成多张订单、跨会话复制附件和独立附件管理中心。
- 自动执行未经用户确认的订单或排产写操作。
