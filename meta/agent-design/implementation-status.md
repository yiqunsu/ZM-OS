## 落地时明确的工程选择

- 快照在短事务内锁 Session，再读消息、工作项、Run 与 cursor；所有 v2 写入共用该锁。替代初稿的 REPEATABLE READ 只读事务，避免认证已开启事务后切换隔离级别。
- 命令先取得“用户＋幂等键”的 advisory lock，再锁 Session。此锁与排产输入锁分开，不阻塞其他会话的模型调用。
- GC 短事务领取作业并执行本地幂等 unlink，失败持久记录退避时间；进程死亡回滚后可重新领取。
- executor 按 `(graph_key, graph_version)` 注册；未注册版本以 GRAPH_VERSION_UNAVAILABLE 结束，不回退旧图。
- 指纹保持确定性服务的字段映射形式，包含 schema_version、待排集合、订单内容、可用设备集合及各设备能力/队列摘要。
- 浏览器测试模拟业务 API/模型结果，实际运行 Next.js、React 和浏览器；另有真实 Next.js 代理的未登录/跨站拒绝检查，以及通过本地 HTTP 流验证的 SSE 重连游标/刷新恢复检查。这些不代表浏览器到真实模型的完整 E2E。
- 另有 `npm run test:agent:fullstack`：真实开发登录 → Next.js 代理 → FastAPI → PostgreSQL 队列 → 独立 Worker → 两个实际 LangGraph → 本地 OpenAI HTTP 测试服务。业务 API、Graph、工具与 Worker 均未替换；仅模型输出使用合成结果。随机空库经完整迁移后运行，退出删除临时数据库、附件和子进程。已加入独立 Agent CI 工作流。
- Worker 的 Phoenix 模式隐藏输入、输出和图片。图片提取走受控多模态 HTTP，不将图片字节放进 LangChain Trace。新业务审计不存正文，token 统计不完整时审计计数为 NULL。
