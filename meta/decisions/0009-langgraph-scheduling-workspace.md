# 0009 受限 LangGraph 排单助手与草案看板

状态：Accepted

日期：2026-09-08

## 决策

development 分支以轻量 LangGraph 排单助手为主运行时。Agent 负责理解、查询、生成草案和解释，生产规则仍由 FastAPI Service 执行。OpenClaw 保留为显式可选运行时，不参与默认部署。

首期交互是：对话生成草案 → 右侧看板人工调整 → 明确确认后执行。实际队列只读展示并轮询刷新；草案编辑不修改生产任务。确认必须绑定草案内容版本，后台变化或另一个页面编辑后应拒绝旧确认。

Agent 图通过受限能力接口与业务交互，不导入 ORM 或 HTTP Router。工具仅允许读取看板、读取当前草案和生成草案；不向模型开放生产写工具。提示词采用版本控制的 Markdown 文件。业务执行由已认证的显式确认 API 完成。

暂不增加独立 Agent 容器、MCP、自然语言调整工具或 multi-agent。能力接口为将来远程适配保留边界，当前使用进程内适配器。

## 验收

- 生成方案后，模型读取工具结果并解释；未执行前无生产任务变化。
- 草案支持人工分配、退回、合并与顺序调整；后端重新计算展示字段和检查兼容性。
- 同一订单不得重复分配；非法修改原子失败。
- 旧版本草案、过期业务输入、越权访问和重复执行均被拒绝。
- 右侧实际队列自动刷新，不能覆盖草案；网络失败显示错误。
- Prompt 修改可通过模拟模型的循环测试和真实排单样例检查。

## 发布

服务器从 development 的指定提交构建镜像并记录提交号。分支名不是镜像版本；推荐以 Git SHA 标记镜像。测试和人工验收前不将开发分支视为生产就绪。保留数据库与附件成组备份和回滚流程。
